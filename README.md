# GEOA-Grad-Work

A simulation of gravitational effects on light in curved spacetime, using Projective Geometric Algebra (PPGA) for mathematical formulation and ray tracing–based visualization. 
The simulation models light propagation near a Schwarzschild black hole through geodesic-based particle motion.

The project uses the FlyFish PPGA library for geometric algebra operations:
https://github.com/fdlombae/FlyFish
